# Console Banking System

A simple Java-based banking application that allows users to manage bank accounts and perform basic banking operations through a console menu.

## Features

* Open a bank account
* Deposit and withdraw money
* Transfer funds between accounts
* View account statements
* List all accounts
* Search accounts by customer name

## Technologies Used

* Java
* Object-Oriented Programming (OOP)
* Java Collections
* Exception Handling

## How to Run

1. Clone or download the repository.
2. Open the project in IntelliJ IDEA.
3. Run `Main.java`.
4. Follow the console menu to perform banking operations.

## Note

This is a learning project that demonstrates core Java concepts and basic banking operations.
